First Prompt - tokenize (9/8/2026):
---------------------------------------------------------------------------------
create a c++ function 
void tokenize(const string str, queue<string>& tokens);
The function has two arguments, the first 'str' is a string of indeterminate length that contains noisy text. The second 'tokens' is where the function should store results.
The function should parse str into tokens according to the following rules, any letter or symbol should be it's own token, and adjacent numbers should be combined into one token. Avoid using isdigit or similar functions, make decisions using ascii values.
Example: str = "f5d.;49:d.sr06" -> tokens = ["f", "5", "d", ".", ";", "49", ":", "d", ".", "s", "r", "06"]
---------------------------------------------------------------------------------
GPT response:
---------------------------------------------------------------------------------
#include <string>
#include <queue>

using namespace std;

void tokenize(const string str, queue<string>& tokens)
{
    for (int i = 0; i < str.length(); i++)
    {
        // Check if current character is a digit using ASCII values
        if (str[i] >= '0' && str[i] <= '9')
        {
            string number;

            // Collect all adjacent digits
            while (i < str.length() && str[i] >= '0' && str[i] <= '9')
            {
                number += str[i];
                i++;
            }

            tokens.push(number);

            // The for-loop will increment i again, so move back one
            i--;
        }
        else
        {
            // Every non-digit character gets its own token
            tokens.push(string(1, str[i]));
        }
    }
}

Second Prompt - strToInt (9/11/2026):
---------------------------------------------------------------------------------
This code is part of a program to extract IPv4 addresses from noisy text. Create a helper function int strToInt(string str); that takes a string input and converts it into a number. We can assume that any number that is input to the function will always be an integer so no need to check. Do not use functions like stoi(), instead do math (possibly using ascii values if optimal) to convert the number. The function will only be called inside a try catch block so you should throw an exception if an issue is encountered. Reject strings that have leading zeros ("02") or any number above 255.
---------------------------------------------------------------------------------
GPT response:
---------------------------------------------------------------------------------
int strToInt(string str)
{
    if (str.empty())
        throw invalid_argument("Empty string");

    // Reject leading zeros, e.g. "02"
    if (str.length() > 1 && str[0] == '0')
        throw invalid_argument("Leading zero");

    int value = 0;

    for (int i = 0; i < str.length(); i++)
    {
        // Make sure the character is a digit using ASCII values
        if (str[i] < '0' || str[i] > '9')
            throw invalid_argument("Non-digit character");

        // Convert ASCII digit to its numerical value
        int digit = str[i] - '0';

        // Build the number
        value = value * 10 + digit;

        // IPv4 octets cannot exceed 255
        if (value > 255)
            throw invalid_argument("Number greater than 255");
    }

    return value;
}

Third Prompt - decimalToIP (9/11/2026):
---------------------------------------------------------------------------------
Create another helper function, string decimalToIP(const unsigned long outAddress);
this function should take the decimal value for an IPv4 address and return the string representing the address in dot decimal format (input: 2821396228, output: "168.43.23.4")
---------------------------------------------------------------------------------
GPT response:
---------------------------------------------------------------------------------
string decimalToIP(const unsigned long outAddress)
{
    unsigned long a = (outAddress >> 24) & 255;
    unsigned long b = (outAddress >> 16) & 255;
    unsigned long c = (outAddress >> 8) & 255;
    unsigned long d = outAddress & 255;

    return to_string(a) + "." +
           to_string(b) + "." +
           to_string(c) + "." +
           to_string(d);
}
---------------------------------------------------------------------------------
This code works using bitwise shifts and bitwise AND operations to split the number into the four octets, then concatenate them for output. 
Bitwise ANDs prevent digits from other octets being included.
Since this was the last addition to the code, it was not tested individually and was rather tested during the final testing phase.
